# Task 024 — Web Start/Finish Input

Статус: идея и пользовательский сценарий зафиксированы; подробное ТЗ не подготовлено,
реализация не начата. Предпосылка: завершённая и принятая
[Task 023](023-fit-only-web.md); использовать endpoint contract общего pipeline
[Task 022](022-fit-only-reconstruction.md).

## Цель

Дополнить одну страницу `/fix` необязательными стартом/финишем или общей точкой
одного кольца для восстановления отсутствующих краёв FIT без GPX. Точки не
требуются для обработки внутренних пропусков.

## Предлагаемый сценарий

1. Пользователь загружает FIT и, если есть, GPX. Оба блока видны сразу и одинаково
   заметны; сценарий FIT+GPX сохраняется без ввода ручных точек.
2. Для FIT-only система выполняет предварительное чтение, детекцию и проверку
   покрытия через Core. Не дублировать detector и coverage logic в браузере.
3. Если покрытие позволяет восстановление и отсутствует начало или конец,
   показать сохранённые участки FIT на карте и предложить соответствующую точку.
   Например: «В начале записи отсутствуют координаты примерно за 12 минут,
   в конце — за 28 минут. Укажи места старта и финиша, чтобы попробовать
   восстановить эти участки».
4. Пользователь указывает только старт, только финиш, обе точки либо одну общую
   точку кольца. Можно выбрать «Продолжить без точек»; тогда края остаются
   unresolved, а внутренние пропуски обрабатываются по прежним правилам.
5. Запустить восстановление с выбранными подсказками и показать результат.

Если пригодные края уже сохранены, не требовать от пользователя их указания.
Если coverage недостаточно или не вычисляется, точки не являются обходом gate;
использовать сценарий отказа и предложения GPX из 023.

## Ввод на карте

- Карта открывается в районе сохранившегося FIT. Первая и последняя пригодные
  GPS-точки подписаны «Первая сохранённая точка» и «Последняя сохранённая точка»;
  не выдавать их за фактические старт и финиш.
- Действия «Указать старт» и «Указать финиш» задают роль следующего маркера.
  Маркер можно переместить, удалить или изменить через координаты.
- Предусмотреть альтернативу «Вставить координаты»: пара latitude, longitude
  перемещает карту и устанавливает соответствующий маркер.
- Для телефона рассмотреть перекрестие в центре карты и кнопку «Поставить точку
  здесь»: пользователь двигает карту под перекрестием.
- Явный флажок «Старт и финиш в одном месте — одно кольцо» оставляет один общий
  маркер. Не включать кольцо автоматически по близости концов; несколько кругов
  не входят в сценарий.
- Пояснение: точка условно относится к началу/концу записи; время вводить не нужно,
  результат может быть приблизительным. Точки не дают права менять сохранённое
  правдоподобное движение. При добавлении GPX ручные подсказки не передаются.

Предварительный анализ потребует состояния ожидания пользовательского решения
между загрузкой и реконструкцией. Его API, хранение, ограничения и повторное
использование результатов Core нужно проработать в будущем подробном ТЗ.
Поиск места по названию, поставщик геокодирования и окончательная мобильная
механика пока не согласованы. Этот документ не определяет схему API, разбивку
реализации или подробные acceptance criteria.
